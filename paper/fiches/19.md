# 19 · MARG: Multi-Agent Review Generation for Scientific Papers

- Référence : D’Arcy, M., Hope, T., Birnbaum, L., Downey, D. (2024). MARG: Multi-Agent Review Generation for Scientific Papers. Prépublication arXiv:2401.04259v1.
- Liens : https://arxiv.org/abs/2401.04259 ; code : https://github.com/allenai/marg-reviewer
- Lu : texte intégral, v1 ; pages de cette version.
- Question : comment produire des commentaires de relecture spécifiques pour des articles plus longs que le contexte du modèle ?
- Méthode : plusieurs instances de GPT-4 se partagent le texte et échangent des messages ; des agents « experts » traitent séparément expériences, clarté et impact (variante MARG-S) (p. 1–2).
- Résultats : dans l’étude utilisateur (9 chercheurs volontaires, qui notent chaque commentaire, p. 13), la part de commentaires génériques passe de 60 % à 29 %, avec 3,7 commentaires jugés bons par article, soit 2,2 fois plus que la meilleure référence (p. 1).
- Relation au projet (notre analyse) : découper le document et spécialiser les appels améliore la spécificité ; notre pipeline découpe aussi par sections, mais pour extraire une structure plutôt que pour relire.
- À citer pour : la réduction mesurée des commentaires génériques ; le découpage des documents longs.
