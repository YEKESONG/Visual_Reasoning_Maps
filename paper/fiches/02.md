# 02 · Graphologue: Exploring Large Language Model Responses with Interactive Diagrams

- Référence : Jiang, Peiling; Rayan, Jude; Dow, Steven P.; Xia, Haijun (2023). *Graphologue: Exploring Large Language Model Responses with Interactive Diagrams*. Version consultée : notice primaire liée ci-dessous.
- Lien : https://arxiv.org/abs/2305.11473
- Question : Comment explorer une réponse de LLM ?
- Méthode : Diagrammes interactifs d’entités et de relations, questions locales.
- Résultat / portée : Le système permet une exploration non linéaire.
- Relation au projet (notre analyse) : Relier sélection graphique et contexte textuel.
- À citer pour : la transformation d’une réponse de LLM en diagramme où l’on interroge un élément précis, ce qui lie la sélection graphique au contexte textuel.
- 待核实：实验协议（参与者、任务、指标）与引用页码。
