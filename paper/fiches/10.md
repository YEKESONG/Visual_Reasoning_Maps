# 10 · Methods for Visual Understanding of Hierarchical System Structures

- Référence : Sugiyama, K., Tagawa, S., Toda, M. (1981). Methods for Visual Understanding of Hierarchical System Structures. *IEEE Transactions on Systems, Man, and Cybernetics* 11(2), 109–125. DOI 10.1109/TSMC.1981.4308636.
- Liens : https://doi.org/10.1109/TSMC.1981.4308636 ; documentation d’ELK Layered : https://eclipse.dev/elk/reference/algorithms/org-eclipse-elk-layered.html
- Lu : métadonnées de l’éditeur (Crossref) ; méthode décrite d’après la documentation d’ELK, qui l’attribue explicitement à cet article. Texte intégral non accessible (IEEE).
- Question : comment dessiner automatiquement une hiérarchie de façon lisible ?
- Méthode (d’après ELK) : approche par couches qui oriente le plus d’arêtes possible dans une même direction : placer les nœuds en couches, réordonner les couches pour réduire les croisements, puis calculer les coordonnées des nœuds et des coudes.
- Relation au projet (notre analyse) : le prototype utilise ELK Layered pour disposer les étapes de gauche à droite, des raisons vers les conclusions.
- À citer pour : l’origine de la disposition en couches utilisée par le prototype.
