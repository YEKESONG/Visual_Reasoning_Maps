# 21 · Tech Overview: Stanford Agentic Reviewer

- Référence : Jiang, Y., Ng, A. Tech Overview: Stanford Agentic Reviewer. Page web non datée, consultée le 23 septembre 2026.
- Lien : https://paperreview.ai/tech-overview
- Lu : page complète.
- Question : description d’ingénierie d’un système qui produit un retour sur un article.
- Méthode : conversion du PDF en Markdown, recherche d’articles liés sur arXiv par requêtes web de précision variable, sélection et résumé des travaux pertinents, rédaction d’un retour selon un modèle.
- Résultats (rapportés par les auteurs, sans évaluation indépendante) : calibré sur des soumissions à ICLR 2025 (150 pour l’ajustement, 147 pour le test) ; corrélation de Spearman de 0,42 entre le score du système et celui d’un relecteur, contre 0,41 entre deux relecteurs ; AUC de 0,75 pour prédire l’acceptation, contre 0,84 pour les scores humains.
- Limites déclarées : erreurs possibles, moindre qualité dans les domaines peu présents sur arXiv, anglais seulement, usage prévu pour les auteurs et non pour les comités de programme.
- Relation au projet (notre analyse) : exemple de documentation technique à ne pas confondre avec une évaluation publiée ; le prototype ne calcule pas de score global.
- À citer pour : l’architecture d’un relecteur agentique et le statut de ses chiffres.
