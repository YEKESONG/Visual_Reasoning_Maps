# 学术阅读界面设计

## 色值与用途
- 纸色 #f4f1e9：阅读工作台背景。
- 墨色 #202d32：正文与图节点标题。
- 青绿 #245d5b：支持关系、主操作、来源定位。
- 赭色 #a15b2b：部分支持与待核实提示。
- 暗红 #a3393d：矛盾，同时使用虚线和文字。
- 边线 #d4d7ce：图网格、证据面板边界。

标题 Georgia 衬线，呼应论文阅读；控件和正文 system-ui；句子 ID 用 ui-monospace。字体本地可用。

## 布局
```
Visual Reasoning Maps                    Bibliothèque | Texte intégral
论文题名                                      核验状态
关系筛选 · 聚焦链 · 带读顺序 · 上一步 / 下一步
┌─────────────────────────────┬───────────────────┐
│       主流程 → → →           │ 步骤标题 / 状态     │
│       分叉、汇聚、子流程        │ 引文 / 推导说明     │
│                       小地图 │ 原版片段 / 修改建议 │
└─────────────────────────────┴───────────────────┘
```

## 原则与自查
图承载论证结构，面板承载验证。节点边线与类型文字结合；待核实采用虚线框。主流程保持 5–12 步，子流程按需展开。Tab/Enter/Esc、可见焦点、减少动画；1024px 以上可操作。

模板化自查：不用装饰性大图、渐变、全大写微标签、区块淡入或统一卡片阴影。论文式排版、原文锚点和可辨的论证线条构成视觉主题。截图与问题修正记录在 DEVLOG。
