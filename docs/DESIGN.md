# 界面设计

## 定位
这是一个本机运行的论文阅读工具，不是产品官网。首页只做两件事：新建图谱、打开已有图谱。图谱页的主体是推理图，右侧面板负责核对原文。界面文字说明"点击后会发生什么"，不写口号。

## 颜色
- 纸色 #f6f4ef：页面背景；面板 #fffdf9。
- 墨色 #1f2a2e：正文、结论类步骤的色条。
- 青绿 #245d5b：主操作、支持关系、论断类步骤。
- 赭色 #9a5a24：因果关系、证据类步骤、"部分支持/待核实"提示。
- 暗红 #a3393d：矛盾关系、异议类步骤。
- 石板蓝 #5f7186：细化关系、问题类步骤；橄榄绿 #66784f：前提类步骤。
- 线色 #dcdfd6 / #bfc7bd：分隔线、网格。

步骤类型用左侧色条加文字类型名；关系用颜色加线型（支持实线、因果粗实线、细化点线、矛盾虚线无箭头），非"支持"的关系另有文字标签。颜色之外总有线型或文字可区分。

## 字体
标题、步骤名和引文用 Georgia（中文回退宋体），与论文阅读的语境一致；控件与说明用系统无衬线字体。节点里最小字号 12px。

## 约定
- 状态用文字标出（部分支持、待核实），虚线框只表示"原文支持未确认"，结构问题不影响它。
- 句子 ID 只作为链接的提示信息，界面上显示"第 3 页"或"第 12 段"。
- 示例数据不显示模型置信度，也不生成解释。
- 不使用渐变、阴影卡片、全大写小标签、进场动画和装饰图标；尊重"减少动态效果"设置；键盘焦点可见；1024px 宽度下完整可用。
